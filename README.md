\# NurseCare



NurseCare is a healthcare management system designed to support nursing operations, patient management, and healthcare service delivery.



The platform enables healthcare staff to efficiently manage patient information, appointments, nursing records, and care plans while providing a streamlined digital healthcare experience.



\---



\## Project Overview



NurseCare was developed to improve healthcare workflow efficiency and simplify patient management processes through a centralized web-based system.



The system supports multiple user roles and provides secure access to healthcare information.

\## Installation



\### Clone Repository



```bash

git clone https://github.com/your-username/NurseCare.git

```



\### Navigate to Project



```bash

cd NurseCare

```



\### Restore Packages



```bash

dotnet restore

```



\### Apply Migrations



```bash

dotnet ef database update

```



\### Run Project



```bash

dotnet run

```
